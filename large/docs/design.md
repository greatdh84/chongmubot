# 총무봇 공통 디자인 — LARGE 적용 범위와 SMALL 쪽 메모

확정된 공통 디자인 시안은 없습니다. 그래서 **SMALL 화면(`demo/index.html`)에 이미 있는 값을 기준**으로 임시 공통 토큰을 만들어 LARGE 에 적용했습니다. 공통 디자인이 확정되면 `large/frontend/src/theme.css` 만 바꾸면 됩니다.

## 1. 기준으로 삼은 SMALL 값
| 항목 | SMALL 값 | LARGE 적용 |
|---|---|---|
| 색 | `--bg #f3f7ee`, `--card #fff`, `--ink #1f2a1c`, `--muted #6b7a66`, `--line #e1e9d9`, `--green #3f9b3a`(주요 버튼), `--green-d`, `--green-l`, `--yellow-l`, `--red-l`, `--blue-l` | 같은 이름·같은 값(`theme.css`) |
| 글꼴 | Pretendard(jsDelivr CDN), 14px/1.5 | 같은 CDN·크기 |
| 로고 | 🐸 초록 둥근 사각형 30px, 굵은 초록 글씨 | 상단바 `대모임 총무봇` |
| 상단바 | 흰색 반투명 고정, 아래 선 | 같은 형태(`.top`) |
| 카드 | 모서리 14px, 옅은 그림자, 선 `--line` | `.card`, `.stat` |
| 버튼 | 모서리 10px, 굵게, 기본 흰색, 주요 초록, 고스트 | `button`, `.primary`, `.ghost`, `.small` |
| 입력창 | 모서리 10px, 초점 시 초록 테두리 | `input/select/textarea` |
| 선택지 | `.opt` 테두리 1.5px, 선택 시 초록 배경 | 참석 선택 `.choice` |
| 태그 | 둥근 알약, g/y/r/b 색 | `.pill ok/warn/bad/info` |
| 테마 | 밝은 테마만 | 밝은 테마만(이전의 어두운 테마는 일관성 위해 제거) |

## 2. LARGE 화면 공통 요소
- 모든 화면(로그인·총무·담당자·참가자·수신함) 위에 같은 상단바: **← 시작 화면**(공용 `/`), 🐸 대모임 총무봇, **행사명**, 모드 태그(시연/운영 · 이메일 모의/실제 · LLM Gemini/모의 · 발송 스케줄러 · Vite 개발 서버일 때 표시).
- 채팅 말풍선마다 누가 정했는지 표시: `AI 판단: Gemini (모델)` / `규칙 기반 해석(모의)` / `⚠ LLM 실패 → 규칙 기반 대체` / `코드가 확인 응답 판정`, 그리고 `코드 검증·실행: 도구 이름`.
- 모바일(390px) 점검: 참가자·담당자·총무 대시보드·정산 탭 모두 가로 넘침 없음(표는 카드 안에서만 가로 스크롤), 채팅 입력 16px(아이폰 확대 방지), 상단바 태그 줄바꿈.

## 3. SMALL 에 적용을 제안하는 것 (도총 확인 후, 이번엔 SMALL 코드 수정 안 함)
1. `:root` 토큰을 별도 파일(예: `demo/theme.css`)로 빼면 LARGE 와 한 파일을 공유할 수 있음. 지금은 같은 값을 두 곳에 둠.
2. 상단바에 현재 모드 표시(정적 데모 / 공용 서버 · Slack 연결 여부 · LLM 키 여부) — LARGE 와 같은 태그 형태.
3. 대모임에서 돌아왔을 때의 동선: 지금은 대모임 블록의 "열기"가 떠나기 전에 시작 화면 상태로 돌려 둠(integration-plan §7-1 합의 필요).
4. 초점 표시(`:focus-visible`)를 SMALL 버튼에도 — 키보드 사용 시 위치가 안 보이는 곳이 있음.
